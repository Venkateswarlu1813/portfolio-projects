All input data is generated in `portfolio/data_science.py`. Churn uses a synthetic logistic target; demand uses known weekly seasonality and a trend; transactions are sampled from three predefined customer regimes. These are implementation examples, not estimates of business performance. No external dataset is downloaded, and no private records are used.

Churn results use a validation-selected threshold of 0.30 and an untouched 400-row test split. The demand test is rolling one-day-ahead, using previously observed demand as time progresses. Segmentation scores describe the full synthetic customer set and are not a held-out predictive evaluation.

To reproduce: `python -m portfolio churn-prediction --output examples`, then repeat for `demand-forecasting` and `customer-segmentation`. Small floating-point differences across platforms and dependency versions are possible.
