# Fictional support policies — demonstration only

Refund requests must be submitted within 14 days of the original purchase. Refund eligibility requires a support specialist to review the purchase record. A draft response must not guarantee approval.

Customers who cannot sign in should use the password reset link on the sign-in page. Never ask customers to send a password, verification code, or API key in a support ticket.

To cancel a subscription, a workspace owner should open Billing and select Cancel subscription. Access continues until the end of the paid billing period. Support drafts cannot cancel a subscription.

For a suspected duplicate charge, collect the invoice reference and transaction date, then escalate to the billing team. Do not collect full card numbers. Only the billing team can confirm whether a duplicate charge occurred.
