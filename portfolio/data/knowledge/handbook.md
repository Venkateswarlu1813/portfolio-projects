# Fictional product handbook

The Atlas demo workspace retains daily backups for 30 days. Workspace owners can request a restore through the support desk. A restore replaces the current workspace data with the selected backup.

Atlas project exports are available as CSV. Workspace owners and editors can export project records from Settings, then Export. CSV exports contain project titles, statuses, and creation dates.

The demo workspace supports three roles: owner, editor, and viewer. Owners manage membership. Editors update project records. Viewers can read existing project records.

For onboarding, create a workspace, invite your team members, assign roles, then create your first project. Each workspace has an isolated set of project records.
